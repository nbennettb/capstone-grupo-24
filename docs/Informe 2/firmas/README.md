# Carpeta de firmas

Coloca aquí las fotos/escaneos de la firma de cada integrante, en formato **PNG o JPG**, usando **exactamente** estos nombres de archivo (sin espacios, minúsculas):

- `nicolas_bennett.png`
- `antonio_defrutos.png`
- `claudio_hasbun.png`
- `agustin_irarrazaval.png`
- `joaquin_jimenez.png`
- `alonso_muelas.png`

(También se acepta extensión `.jpg` o `.jpeg` en vez de `.png`.)

Mientras un archivo no exista, el documento compilado mostrará un recuadro con el texto "(firma pendiente)" en su lugar, así que puedes compilar el informe en cualquier momento sin que falle.

Sube estas imágenes a la misma carpeta `firmas/` dentro del proyecto de Overleaf (arrastrándolas a la carpeta) y vuelve a compilar.
